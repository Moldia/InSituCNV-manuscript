# 06_Visualize_results

This stage turns `metrics_master.csv` into summary figures for interpretation and reporting. The notebook (`06_visualize_metrics.ipynb`) generates completeness tables, performance trends (including log-scale counts-per-cell views), per-template heatmaps, template-level summaries, and a refreshed list of runs missing metrics (`results/plots/summary/runs_missing_metrics.csv`).
