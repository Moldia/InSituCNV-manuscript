# 01_Define_CNV_templates

This stage defines CNV template designs (`T01..T10`) before simulation. The notebook (`01_define_cnv_templates.ipynb`) builds template-specific trunk/branch CNV gene sets, generates interval tables (`data/templates/CNVs_T0X.csv`), writes subclone definitions (`manifests/subclone_T0X.json`), and records template metadata in `manifests/templates.csv`.
